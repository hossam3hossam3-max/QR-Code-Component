### What I learned

While working on this project, I improved my understanding of HTML and CSS, especially in creating layouts and styling elements.
Some of the concepts I practiced include:

**1. Using Flexbox to center and organize elements:**
```css
body {
  display: flex;
  justify-content: center;
  align-items: center;
  flex-direction: column;
}
```

**2. Using the CSS Box Model to control spacing:**
```css
.container {
  padding: 16px;
  margin-top: auto;
  box-sizing: border-box;
}
```

**3. Creating visual effects with CSS:**
```css
.container {
  border-radius: 20px;
  box-shadow: 0px 25px 25px 0px rgb(0, 0, 0, 0.0477);
}
```

**4. Importing custom fonts using Google Fonts:**
```html
<link href="https://fonts.googleapis.com/css2?family=Outfit:wght@100..900&display=swap" rel="stylesheet">
```
